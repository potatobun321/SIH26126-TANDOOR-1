# Evaluation & Benchmark Logs

Contains evaluation scripts, trajectory evaluation tools, and benchmark log logs per phase:
- Perception benchmarks (mIoU, precision, recall, latency/FPS)
- Localization error (ATE, RPE, drift over distance)
- Navigation success logs (A→B success rate, collision count, path length vs optimal)
- System compute utilization profiles (CPU/GPU, RAM, latency)
