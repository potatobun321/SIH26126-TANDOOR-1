# Existing Solutions & Research Landscape

Purpose: answer "are we solving something novel, or integrating existing components?" honestly, before any architecture decisions are made.

## Headline answer (CURRENT HYPOTHESIS, to be revisited after Task 7 research is complete)
**Outdoor vision-based autonomous UGV navigation is a mature research area with strong open-source building blocks, but no single off-the-shelf open-source stack solves it end-to-end, robustly, for unstructured/off-road Indian outdoor terrain, on affordable hardware.** Tikka Techies is very unlikely to invent a fundamentally new algorithm class in an SIH timeline. The realistic and defensible position is: **integrate existing, individually-mature components into a system tuned for a specific outdoor use case and constraint set**, and treat the *integration, tuning, and evaluation* as the engineering contribution — not a claimed novel algorithm. This is consistent with the recurring pattern noted in `SIH_WINNER_PATTERN_ANALYSIS.md` that most strong SIH robotics entries integrate rather than invent.

## Existing systems that already solve significant portions of this problem

- **ROS 2 Navigation stack (Nav2):** solves global/local planning, costmap management, recovery behaviors, and controller execution for wheeled ground robots. Mature, widely deployed, actively maintained. Does **not** solve vision-based perception or SLAM itself — it consumes their outputs (costmaps, odometry, TF).
- **Visual SLAM systems (ORB-SLAM3, RTAB-Map, VINS-Fusion, etc.):** solve monocular/stereo/RGB-D localization and mapping. Mature in structured/textured indoor and urban outdoor scenes. Known to degrade in low-texture outdoor terrain (grass, dirt, uniform vegetation), in bright/variable outdoor lighting, and over long traverses without loop closure opportunities — this is a **documented, repeated limitation across the SLAM literature**, not a Tikka-Techies-specific guess.
- **Off-road semantic segmentation research (RELLIS-3D, RUGD, and associated baseline models):** solves terrain-class labeling (trail, grass, obstacle, water, vegetation, sky) for off-road scenes, with published baseline models (e.g., variants of PSPNet, DeepLabv3+, and more recent transformer-based segmenters) achieving moderate-to-good mIoU on these benchmarks. This is the closest existing research to "terrain/traversability perception" but the datasets are US-centric (Texas rangeland conditions for RELLIS-3D; varied US off-road trails for RUGD) — **not validated for Indian terrain, vegetation, or lighting**, which is a real, named gap (see `RESEARCH_GAPS.md`).
- **Military/defense autonomous UGV programs** (e.g., DARPA's historical Demo III / PerceptOR programs, and more recent commercial off-road autonomy stacks): demonstrate that vision+LiDAR fused perception for off-road navigation is achievable at high engineering investment, but these are not open-source and not directly reusable — useful as evidence of feasibility and of known hard failure modes (dust, glare, negative obstacles like ditches), not as a code base.
- **Commercial/academic sim-to-real autonomous off-road platforms** (e.g., university-built ATV/UGV platforms using Gazebo+ROS2+Pure Pursuit, as seen in the GitHub search results during this session) show that a **simulation-first, vertical-slice methodology is a proven, replicable pattern** at student-project scale — directly supporting the phased approach requested in Task 8.

## What does NOT yet exist as a ready-made open-source solution (this is the actual opportunity space — expand in `RESEARCH_GAPS.md`)
- A single, well-maintained, ROS 2–native package that performs **vision-only (no LiDAR) traversability estimation** tuned for unstructured off-road terrain and integrates directly into Nav2 costmap layers. Most public traversability-estimation work is research code (paper repos), not maintained ROS 2 packages.
- Public evidence of **GPS-denied visual localization systems validated specifically on Indian outdoor terrain/lighting** (dust, monsoon haze, dense vegetation, unmarked trails) — RELLIS-3D/RUGD do not cover this; no equivalent Indian dataset was identified in this research pass (flag for Task 6/dataset gap analysis).
- A turnkey combination of terrain segmentation + visual SLAM + Nav2 that has been publicly demonstrated as a single integrated, benchmarked pipeline for GPS-denied outdoor UGV navigation at hobbyist/student hardware cost. Individual pieces exist; the integrated, evaluated combination at this cost point is comparatively rare in public repos.

## Implication for architecture decisions
Because Nav2, visual SLAM, and terrain segmentation are each independently mature, the team's architecture decisions (see `TECHNOLOGY_COMPARISON.md`) should optimize for **integration risk and evidence of ROS 2 compatibility**, not for picking the "most advanced" algorithm in isolation. A well-integrated combination of moderately capable, well-supported components that actually runs end-to-end and is properly evaluated will beat a state-of-the-art component that never gets integrated — this principle should be written directly into `AGENTS.md`.
